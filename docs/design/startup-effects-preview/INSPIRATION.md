# 月蚀前奏：六种文字成圆的方法

2026-09-09。用户认可旧版「月蚀显影」水流切割的后半段，本轮只改前半段。仍是独立代码预览，待用户选定后再考虑 App 接入。

## 本轮新增参考

- [Vincent Schwenk](https://vincentschwenk.de/)：官网将其创作描述为流动的雕塑，并陈列 3D 动态项目。[Live show Pt. 3](https://vincentschwenk.de/works/peggy-gou-copy) 包含 CHOCOLATE 系列。由此引出“字母是可接触、挤压的柔软实体”，应用到墨滴与软枕方案。
- [Zach Lieberman](https://zach.li/)：以代码制作实验绘画和动画工具，将计算作为表达媒介。由此引出“文字不是一张贴图，而是能在空间里弯曲的一条材料”，用于字环方案。
- [Matt DesLauriers / Meridian](https://meridian.mattdesl.com/)：通过大量小笔触建立分层的形态。这里借用“层层累积形成整体”的组织原则，改写成少量可追踪的卷带；不模仿作品的地貌或配色。
- [Lucas Zanotto / Mood Rollers + Flippers](https://www.lucaszanotto.com/work/moodrollers)：官网展示轴向排列的几何体和滚动构成，作为几何动作参考。字母滚动和归位的分镜是本次设计推演，不声称原作存在“字母变月亮”的动画。
- [Jono Brandel](https://jonobr1.com/) / [作品目录](https://works.jonobr1.com/)：其官网说明图形设计与编程结合的实践，目录包含 Patatap、Typatone、Mellow Waves。借用图形动作与节奏相互组织的思路，用于错峰滚拢与回弹节拍。
- [Universal Everything](https://www.universaleverything.com/profile)：关注数字形体的生长、运动与变化，以及技术与自然的关系。这里把它转译为“相向的潮水包住一个圆”的前奏。

以上是参考事实和设计推演的区分；六个具体 Relayune 分镜与代码均为本次创作，未使用艺术家视频或图片作为动画资产。

## 六种方案

| 方案 | 成圆过程 | 与水流收尾的关系 |
| --- | --- | --- |
| 01 字母滚月 | 可读字母逐个倾倒、滚拢，分散的重量落到中央 | 小动作归静后，让水流成为最后一次大动作 |
| 02 弯字成环 | 一行文字弯成字环，环的内缘收拢填满 | 前段圆周运动，后段横向切割形成方向对比 |
| 03 卷带入月 | 字标成为软带，绕入月盘，层与层贴合 | 材料连续流动，收尾像在同一材料里开出河道 |
| 04 墨滴相拥 | 字母润成少量墨滴，接触、融合并抹平轮廓 | 先凝聚、后流过，保持同一种柔软质感 |
| 05 潮汐包合 | 文字两端像两股潮水向内卷，包合满月 | 前段相向，后段单向，把运动方向整理清楚 |
| 06 柔弹成圆 | 字标收成软枕，轻微压缩和回弹后成为圆 | 回弹幅度归零，再接平稳的水流划过 |

共同要求：文字不凭空消失；前奏结束时位置、半径和颜色一致；字腔闭合要连续；没有绿色条；不改已经认可的水流切割路径和时间参数。

## 代码与验证边界

新的 `EclipseFormation` 覆盖归一化变形进度 `[0, .53)`；从 `.53` 起调用共用 `_paintEclipse`。后续根据用户指出的尖角伸缩问题，六种前奏启用 `stableEnding`：保留水流路径与时序，移除末段半径/通道宽度补偿，始终绘制同一矢量轮廓，加载只改变明暗。测试比较补偿开始前的原版帧、切割结束到末帧的稳定性、正式图标轮廓、成圆接缝及加载不缩放。预览保留旧版对照、重播、半速与时间轴。
