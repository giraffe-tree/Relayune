# 手机端现状核查与设计修订

2026-09-28。以实际 iOS 模拟器截图修订，前两版通用 HTML 原型不再作为视觉基准。

## 设计背景与证据边界

本说明保留导航和界面设计约束。原有个人设备标识、安装状态、截图与本机原型位置留在私有维护仓库，内部验收档案未随公开源码提供；不能据本文认定公开副本已经过当前版本实机验收。

## 之前原型的问题

之前在没有先查看实机的情况下，把手机端画成了通用任务列表，移除了现有纵向 Agent 栏、项目折叠结构、工具执行时间线与模型设置。浅色表现、信息密度和新建入口也与产品不符。那些原型只能表达部分路由意图，不能作为 UI 实现依据。

## 必须保留的产品结构

1. 深色背景、薄荷绿状态色、Relayune 品牌图标和较克制的卡片边框。
2. 首页的品牌栏、问候语、最近会话分组、全部已读与 Token 消耗区域。
3. 抽屉现有的两列：左侧 Agent 栏，右侧项目与会话树；底部账户入口。
4. 对话页顶部导航、运行状态、工具执行时间线、可折叠输出、模型配置和底部输入区。
5. 设备页的电脑版本、连接状态、Agent 状态、独立授权和诊断能力。

## 四页如何调整

### 首页

保留原版品牌栏、问候语、最近会话和 Token 消耗。根据用户标注，删除独立电脑名称与切换条。最新确认：首页“最近会话”旁按电脑展示不同颜色的电脑图标，直接点选切换，不显示名称、下拉箭头或弹出菜单；一次显示一台电脑，切换同步更新最近会话、已读操作和 Token 统计。右上角现有电脑图标继续进入设备管理；数据仍属于抽屉选中的电脑。

### 抽屉

顶部改为可以横向滑动、直接点选的电脑条，当前项高亮，后续电脑露出部分内容提示可滑动。点击后留在抽屉，Agent 与项目树一起更新；关闭抽屉进入目标电脑首页，避免把旧会话显示在新电脑上下文下。
保留原有左侧纵向 Agent 栏、右侧项目树、项目内新建会话、底部账户入口，不新增业务实体。

### 对话页

删除电脑名称及切换入口，保留项目/会话标题、Agent、分支、运行状态、工具时间线、模型设置和输入框。电脑切换统一经过抽屉。草稿仍绑定原电脑和原会话，后台任务继续执行。

### 设备页

首屏只显示已添加电脑列表与底部“添加电脑”。每台电脑增加清晰的 SVG 设备图示，显示名称、在线状态及当前使用状态。
删除顶部重复的“添加”入口，删除列表底部“连接与授权”、手机版本及加密说明区域。
点电脑行进入该电脑详情，仅查看，不自动切换工作电脑。详情保持模拟器现有布局和顺序：电脑摘要、大型实时连接拓扑、完整 Agent 列表、技术详情、端到端加密边界、添加电脑及移除连接。以上内容不折叠或重新组织。
“添加电脑”直接进入扫码页，手动输入连接码作为次级入口。HTML 的相机区域标注为交互示意，不启用真实相机或执行真实配对。

## 成熟产品参考与取舍

- [Slack：切换工作区](https://slack.com/help/articles/1500002200741-Switch-between-workspaces)：手机端从 Home 右滑后选择目标。借鉴“上下文切换属于导航层”，但 Relayune 保留显式点按入口，不能只靠隐藏手势。
- [Linear Mobile](https://linear.app/mobile)：官方强调手机上快速查看与处理重要工作；其紧凑层级和按需详情适合任务监控。借鉴视觉克制和操作密度，不照搬底部导航。
- [Linear 手机导航定制](https://linear.app/changelog/2026-01-22-customize-your-navigation-in-linear-mobile)：其底部工具栏服务于自己的主要功能。Relayune 已有 Agent 栏与项目树，因此本轮不叠加第二套导航。
- [Notion 手机工作区](https://www.notion.com/en-us/help/workspaces-on-mobile)：上下文选择和内容层级分开，可用于检查“电脑高于 Agent”的导航关系，不引入其工作区实体。

以上是设计参考，不是这些产品对 Relayune 方案的验证，也不意味着所有竞品功能都适合迁入。

## 本轮实现

首页与抽屉共享选择；对话页隐藏电脑名，切换后进入目标电脑导航，原会话草稿保留。设备列表只保留电脑卡片与底部添加，详情复用原 DevicePage。添加直接打开扫码并在后台准备账号，可选六种电脑颜色；扫描不可用时可返回手动输入。颜色以现有账户和电脑 ID 存手机安全存储，不进入协议、Server 或 Desktop，旧电脑补充本地默认色。

## 原型边界

早期 HTML 为截图核查与修订原型；当前开始实现以上 Flutter 交互。原有设计文档的归属、草稿、迟到回调、通知和授权规则仍适用；页面结构以本文件修订为准。
原型只演示核心导航、电脑面板、任务归属、设备详情与添加入口。配对、账户、新增项目等完整业务流程继续复用正式 App，不能把原型里的示例反馈当成协议实现或验收结果。
