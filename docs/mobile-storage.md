# 手机本地存储

## 用户可见行为

打开已缓存会话先显示本地正文，随后静默核对 Desktop 历史。已有正文时不显示历史加载动画；
主动向上加载旧页才显示“正在读取更早记录”。网络失败保留已显示内容，权限错误仍明确展示。
冷启动在账户/权益请求完成前恢复已保存的加密目录，点开会话时恢复正文，只允许本地阅读；验证成功后恢复实时连接。
首页启动不预读默认会话的正文；已打开会话的在线核对仍在验证后继续。
恢复目录不重建运行状态、待审批状态或在线状态。重入与回前台仍读取最新原生历史，以恢复漏掉的终态。

历史请求每页最多 100 条 Relay 消息记录，同时请求 256 KiB 的传输预算；字节预算可能让
一页少于 100 条。用户消息、助手消息、计划和返回的工具活动都占消息条数，不等同于
100 个 turn 或 100 个 Codex 原生 item。`has_more` 与 `next_cursor` 表示还有更早的连续
历史，向上阅读时接着加载；此上限不删除或限制整个会话的历史条数。

后台五分钟保留及恢复策略见 [手机后台生命周期](mobile-background-lifecycle.md)。

## 保留与淘汰

| 数据 | 保留规则 |
| --- | --- |
| 会话正文和已读取分页 | 全手机最多 100 个会话，跨电脑、账户和 Agent 共享；不按天数过期 |
| 淘汰顺序 | 当前显示的会话优先保护；有待确认输入的会话次之；其余淘汰最久未读取者 |
| 会话访问 | 读取本地页、预览或打开会话提升顺序；后台更新已有正文不提升顺序 |
| 图片 | 最多 500 个会话附件，预览+原图合计一张，同时限制加密载荷 256 MiB；LRU |
| 会话目录 | 每个授权最新加密检查点，最多 300 条目录摘要；不占正文缓存名额 |
| 删除标记 | 保留至对应授权退出/撤销，防止旧页重放；不占正文名额 |
| 未确认发送 | 独立加密保护；原生回显确认或授权清理后移除；不随正文、图片 LRU 回收 |
| 内存 | 当前会话与最近 4 个读取会话；其他运行会话保留最多 100 条尾部消息 |

正文淘汰不会删除电脑上的 Agent 原生会话。被淘汰会话再次打开时可回源；图片缓存命中仍可独立复用。
保护输入不自动重发：Server 接受命令并不等于 Agent 已确认处理，不能把断网或进程退出解释成可安全重试。

## 一致性与写入

`history-v1.sqlite` 的 schema 升至 2。`history_log` 对命名空间、会话、记录类型和消息身份建立
唯一索引；每条消息、页和目录只保存一个最新记录。页成员、游标及正文同事务提交。删除标记须
解密认证且同一 ID 不能恢复；正文被回收后仍保留标记。预览至多恢复最近 100 条正文并合并受保护
输入，不证明历史结束；已缓存页链的检查点仍用于向上读取，不跳过未覆盖区域。

实时更新使用加密事件 AAD 中的来源序号，旧事件不能回退同一消息或实时展示。最新原生历史请求
记录开始时的已知序号：请求期间收到的新事件优先保留；请求后的权威历史可以纠正、缩短旧正文。
旧端未给原生消息提供独立版本号，因此这是客户端的同步基线，不能宣称服务端/原生文件具有统一
全局版本。单个会话只允许一个历史请求在途；缓存命中和网络刷新分别记录状态。

流式输出使用 300 ms 安静窗口及 2 秒最长等待；完成/删除/用户消息立即入队。队列只保留会话和
游标的最新待写内容，落盘时捕获不可变消息对象，避免每个 delta 排队完整历史快照。后台和退出刷新
未完成检查点；操作系统强制杀进程仍可能丢失最后一个未提交窗口，回前台后用原生历史补齐。
最新页与最近预览在同一 SQLite 事务读取，重叠消息只认证解密一次，访问顺序只更新一次。
解密复用仅限该事务，不能跨读取保留旧正文或删除标记。解密按页批量处理，累计密文达到 32 KiB
时使用一个后台 isolate，避免逐条创建 isolate；旧格式仍先认证再迁移。
大于等于 32 KiB 的历史 JSON 编码、加密，以及大附件的受保护输入 Base64 转换移到后台 isolate。
性能记录只包含阶段、耗时、数量、队列深度和载荷字节数，不含内容、密钥或会话 ID。

## 升级与授权清理

v1 升级事务移除追加限制并按旧 seq 保留最新身份记录；旧 AES-GCM AAD 格式保持可解密。
首次读取只迁移当前页和最近预览涉及的记录，不等待整个授权或全部会话迁移。
其余记录后台每批最多读取 4 个旧密文，认证后把内联图片移入统一图片缓存，旧乐观发送保留为受保护输入。
新格式认证来源序号，迁移用 seq/digest 条件更新，避免覆盖并发新写入。所有有效缓存密钥参与
后台维护；迁移前保留旧输入，完成后回收至 100 会话。没有密钥的历史及图片命名空间直接清理。
取消授权等待在途写入及迁移完成，清理数据后销毁密钥；再次授权使用新的缓存命名空间。
SQLite 回收页可复用，不在每次写入后运行 VACUUM。

## 验证

存储测试覆盖真实 SQLite v1 迁移、来源乱序与认证篡改、事务回滚、跨密钥全局 100 会话 LRU、
当前会话保护、删除标记跨淘汰保留、图片移出正文、受保护输入跨正文/图片回收及重启恢复、失效命名
空间清理、大正文最新版本覆盖。Controller/界面测试覆盖离线冷启动、禁止未验证命令、连续输出周期
落盘、原生历史纠正正文、乱序事件不污染实时展示、已缓存会话无加载动画及旧页加载动画。

2026-10-01 验证：最终相关回归 204 项通过，Flutter analyze 无问题，115 个核心用例映射校验通过。
扩展全量回归 797 项通过、1 项原有跳过；唯一失败为提交前已存在的中文账号删除 ARB 缺少
10 个文案键（`test/l10n/localization_test.dart`），本次未修改翻译文件。

大库验收发现并修正首次恢复等待整个授权迁移的问题：改为当前页按需认证迁移，后台批次之间主动让出执行。
该修正相关回归 109 项通过；真实模拟器旧库包含约 1.8 万条消息，使用同一数据原地升级验收。

最新页可在同一事务中先发布最近 20 条及受保护输入，随后补齐原完整页；事务内复用认证结果，预览不确立分页覆盖。首次目录同步未完成便进入后台时，保存已显示目录但不宣称同步游标。性能证据见 完整启动调查（内部验收档案未随公开源码提供）。
