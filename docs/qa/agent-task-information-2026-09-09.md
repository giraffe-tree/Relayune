# 子任务信息层级调整 · 2026-09-09

## 2026-10-10：按可读取的证据收敛手机展示

### 底部任务框反复出现／消失的根因

只读核验本机 Codex 0.160.1 的同一批 88 个子线程，全部 `sessionId` 等于子线程自己的 ID，而不是主会话 ID。历史／任务快照按主会话读取；原来的实时子线程事件却优先用子线程 `sessionId` 填充路由及 `root_session_id`。手机按此字段改写任务归属，任务移出当前主会话时底部框被卸载，随后刷新又把任务移回，展开状态也随卸载丢失。

Relay 统一沿 `parentThreadId` 解析根线程，应用于历史、任务快照、实时协作事件、工具／回复事件及待处理请求；顶层 fork 使用自己的线程 ID。未知或循环父链不伪造根归属。外部 rollout 使用实际读取的线程上下文，不把占位值作为归属。手机端保留已识别任务的根归属，兼容旧 Relay 的子线程自身 ID／占位值；初次收到的错误归属可由已知父会话／父 Agent 恢复，无法恢复时不创建错误任务。

修复前用真实 88 个线程元数据调用事件转换器并仅在本机捕获，88 个事件全部路由错误；修复后全部归属同一主会话。Widget 回归复现旧代码卸载底部框，再验证 80 次交替更新下框与展开状态持续保留。另覆盖嵌套父链、缺失／循环父链、外部日志缺少线程字段，以及历史与实时归属一致。原生页面观察与这些受控协议回归分别报告，不把静态历史观察称为真实模型的连续运行测试。

- Codex 子任务以原生线程标题或任务路径命名，昵称放在详情；保存原生模型与推理等级，界面明确称为模型配置。
- 子线程详情不再固定只读取前 32 个。每批最多 8 个并发，全部读取；终态缓存以源文件指纹和实时事件代次失效，最多 256 条／2 MiB，不保存完整 turns 或工具输出。
- 独立 app-server 的 `notLoaded` 不代表任务未完成。终态以子线程回合为准；独立读取器误判的活跃回合仅由匹配的持久生命周期证据纠正。个别读取失败显示待同步，不影响其他任务。
- 手机主动刷新以请求开始时的任务对象作为基线：允许纠正未变化缓存中的错误状态，不把事件接收时间当作提供方更新时间；请求期间到达的新事件优先保留，其他合并路径仍按时间排序。
- 手机汇总分别统计运行、完成、停止、失败、准备和未知；悬浮窗优先展示需要处理与运行中的任务。按屏幕和文字大小容纳完整预览行，完成后缩为两条；总览可搜索任务标识、昵称和模型。
- 详情顶部展示身份、模型配置和历史会话入口；最新回复不冒充完整历史。目录尚未出现的 Codex 子线程只登记已知身份，不继承主会话的写操作能力。
- 历史入口只关闭任务总览／详情，保留命名为 `workbench` 的会话路由；不能 `popUntil(isFirst)` 返回实际首页。回归必须包含 `RelayuneReadyScreen` 外层路由，直接把 Workbench 放在测试根节点会漏掉此问题。
- 移除手机多 Agent 的原始任务全文、运行信息折叠区、工具／token／上下文指标、估算耗时；子会话历史也不显示由消息时间估算的耗时。不提供进度百分比、预计剩余时间或质量验收结论。

只读真实 Codex 0.160.1 的 88 个历史子线程，经产品适配器确认 87 完成、1 中断、0 运行、0 未知，全部返回模型配置。确定性回归覆盖 88 个任务、分页、限并发、缓存失效、读取失败隔离与活跃回合纠正；Flutter 回归覆盖排序、搜索、长回复前的历史入口、历史多条回复及窄屏。此处不把协议／Widget 验证描述为原生页面验收。

手机会话悬浮窗只保留最多三条任务摘要，任务标题优先，状态与最近活动同行展示；
通过“查看全部”进入独立总览，点击任务进入独立详情。列表不因活动更新时间变化重排。
完成结果保留入口，主任务结束后不隐藏整个窗口；不展示进度数字或秒级计时。

总览按需要处理、进行中、已结束展示任务，保留已知父任务关系、最近更新时间及结果摘要。
详情优先展示提供方已返回的结果/摘要与可点击链接，审批仅依据精确的 source thread/agent ID
归属显示。任务原文、活动时间线和运行信息按需展开，可打开原生子会话时保留入口。
新文案提供中文与英文，其他语言沿用 Flutter 的英文回退。

Codex 未加载或无状态时标记 unknown，不再冒充 pendingInit；子任务快照不借用主任务创建时间，
当前子线程轮次状态优先于历史委派项。Claude 后台启动返回不算完成，使用对应任务的结束通知；
只在原生报告后填入子任务模型。稀疏刷新不清除已经收到的模型、用量和结果。
