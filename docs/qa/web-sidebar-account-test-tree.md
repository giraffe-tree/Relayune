# Relayune Web 侧边栏与账户菜单测试树

本文是 Web 工作台侧边栏的可勾选验收清单：

1. 把工作台底部的客服、价格、服务条款和隐私政策入口迁入项目侧边栏，不再占用主页面高度；
2. 账户卡片固定在侧边栏底部，展示邮箱与账户操作，点击向上展开账户菜单，只有显式选择“退出登录”才注销；
3. Agent 图标长按 420ms 后拖动排序，松手按账户保存到 MongoDB，Alt + 上下方向键也可排序。

用例 ID 不复用。`P0` 是发布阻断项，`P1` 是主要体验回归项；`A` 表示适合自动化，
`M` 表示需要浏览器人工验收。勾选时应在用例后附执行日期、浏览器/视口和证据位置，
不得把 Cookie、浏览器授权令牌、设备令牌、短码或 E2EE 密钥写入截图、日志和文档。

## 执行基线

- 已登录邮箱账户，且当前浏览器已经通过一次性短码 PAKE 绑定一台 Desktop Relay；准备至少一个项目和一个会话。
- 中英文各执行一轮；桌面至少覆盖 `1440×900`、`1024×768` 和 `821×700`，移动至少覆盖
  `390×844`、`320×568`，并单独检查 `820px / 821px` 响应式边界。
- 浏览器至少覆盖一个 Chromium 内核和一个 WebKit 内核；键盘用例不使用鼠标辅助。
- 网络面板只记录请求方法、路由、状态码和次数；核对 IndexedDB 时只判断记录存在或不存在，
  不展开、复制或输出密钥与浏览器令牌值。
