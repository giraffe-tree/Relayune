# 手机端多电脑连接

用户 → 电脑 → Agent，沿用现有项目和任务。电脑来自已有独立授权，不引入工作区、连接组或新的服务端业务表。

## 使用行为

- 首页默认汇总已授权电脑的任务，显示所属电脑；可筛选一台电脑。
- 首页抽屉先选择电脑，再使用原有 Agent、项目和任务导航。任务页标题带电脑名，发送、停止、审批、文件、模型配置等操作始终使用该任务所属电脑的连接。
- 设备页列出电脑，可添加另一台、查看连接、重新连接或单独移除。添加过程中原连接继续工作；重新授权同一台只替换它的旧授权。
- 各电脑独立维护实时连接、授权凭据、缓存密钥、项目别名、已读状态、会话草稿和阅读位置。账户、语言、字号及通知等账户偏好共享。
- 退出账户会停止所有连接并销毁各电脑的本地历史密钥。原有配对记录按账户保存，恢复时校验当前登录账户。升级保留原单电脑配对，不要求重新授权。

## 通知兼容

手机内部的通知和动态卡片目标包含电脑、授权及原任务 ID；发送给电脑的协议 ID 不变。重新授权后旧通知不能操作新授权；旧版未带电脑的通知仅在目标唯一时打开。

Android 服务端允许同一个推送 token 保留同账户多台电脑的绑定，换账户时清理旧账户绑定，单独移除只注销对应授权。启动时将原 registrationHash 唯一索引转换为普通索引，保留授权主键和 TTL；注册与注销串行处理。推送仍仅含通用提示和不透明回执。

iOS 手机端扩展本地密钥绑定列表，按 kid 选择密钥，动态卡片 token 按电脑注册；兼容旧单绑定格式。iOS 服务端及电脑端协议不变。

## 验证与上线边界

自动化覆盖多电脑恢复、同名/同 ID 任务路由、重新授权、独立移除、取消添加、草稿与首页筛选、并发存储、推送多绑定与注销竞态、Android 索引迁移和账户隔离。原有手机端全量测试、服务端配对与推送测试继续执行。

本次为本地开发改造。Android 多电脑后台推送需要部署配套服务端代码后才能完整生效；本次不执行生产部署。真实两台电脑与手机厂商推送的端到端验收需在配套测试环境继续验证，不能由单元测试或模拟器替代。
