# 性能测量方法

公开副本保留[报告模板](report-template.md)，历史真实设备测量、原始数据与诊断补丁留在私有维护仓库，不作为公开源码的一部分。

每轮测量应记录目标版本、对照版本、设备与系统、构建模式、网络、缓存清理范围、样本规模和有效样本数。区分进程启动、首帧、首页就绪、历史首屏与最终回复，不用构建成功代替用户路径验收。

在相同条件下比较逐次耗时、字节与计数，报告中位数及最小/最大值；设备、构建、网络、缓存或负载变化时建立新基线。无效样本单独说明原因，小样本不报告 P95，不把部分结果当作完整一轮。

使用合成夹具或事先脱敏的样本。不得将真实会话正文、设备标识、短码、内容密钥、token、账号或完整运行日志提交到公开仓库。生成的报告与测量数据先在本地审查，再决定是否公开。
