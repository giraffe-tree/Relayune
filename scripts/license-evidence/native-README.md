# Native desktop license evidence

`native-desktop-manifest.json` maps exact package versions and original archive SHA-256 values to complete publisher texts, original publisher declarations and separate standard-license terms. All copied documents use content-addressed filenames; the generator rejects changed bytes. Project MIT licensing is separate from these third-party terms.

- Node v22.23.1: the complete official fixed-tag LICENSE, including its embedded library notices. The selected original pkg-fetch runtime must match the installed, locked pkg-fetch3.6.4 expected SHA-256. The built sidecar must report the same Node version and intended architecture through Node-only `PKG_INVOKE_NODEJS`; this never runs the Relayune application bootstrap. pkg6.21.0 and pkg-fetch3.6.4 original license texts cover their injected bootstrap/patch source separately, with the corresponding source-input hashes recorded.
- Rust crates: original `.crate` archives are verified against Cargo.lock and selected with `cargo metadata --locked --offline --filter-platform`. Root license/NOTICE/COPYING/COPYRIGHT documents are retained with original text and attribution. Development-only dependencies are omitted; build dependencies remain. The selected dependency set is a declared target superset, not proof of exact linker inclusion.
- Missing package-owned permission text: alloc-stdlib, tauri-plugin and UNIC use original upstream texts at the `.cargo_vcs_info.json` commit. The objc2 family retains that exact revision's original LICENSE.md, including its Apple SDK discussion, and appends unmodified SPDX MIT terms under the publisher's explicit MIT option. siphasher preserves its original COPYING attribution and MIT link, adding the same separate standard terms.
- sigchld0.2.4: the published Cargo.toml.orig is byte-identical to the fixed upstream Cargo.toml, declares MIT, and identifies Jack O'Connor as author. The original archive matches Cargo.lock. This authentic declaration/author text is retained with unmodified SPDX MIT terms. `upstream_license_file_missing:true` records that no separate upstream LICENSE was found. No copyright year or holder has been filled into the standard template.
- selectors0.36.1: its exact upstream/source header invokes MPL2.0 and the Mozilla URL. The header and separate fixed SPDX MPL2.0 terms are retained. All selected MPL crates also carry original checksummed source archives and their exact source URLs. A byte comparison of every original archive file against the installed source rejects modified MPL sources until actual corresponding modified source is provided.
- Rust1.93.1 standard library: the installed toolchain's complete `COPYRIGHT-library.html` is byte-identical to the file in the official `rustc-1.93.1-aarch64-apple-darwin.tar.xz`, whose published archive SHA-256 was verified. The file is copied unchanged and checked against the selected rustc version and installed notice bytes. Its exact distribution-archive URL, member and checksum are recorded in the manifest.

The sidecar preparation pipeline writes these materials into `desktop/src-tauri/resources/generated-notices/native-desktop/` for Tauri's existing resource mapping. This generated directory is ignored by Git. A final `--verify-app` independently compares the actual App's resource hashes with the generated inventory, checks the JS notice text and project license, probes host Node metadata and records the actual main/sidecar executable hashes. The signed installer/archive hash, signature verification and real business-entry acceptance remain separate release checks.

This evidence is for current macOS targets. It does not clear Windows/Mobile SDKs, system-provided Apple frameworks, or every possible precompiled component on another target. A complete notice selection does not assert an exact native link map or give a general legal opinion.
